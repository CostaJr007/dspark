# DSpark Repository & Agent Guidelines

## 🧠 Mandatory Metacognitive Protocol:
1. **Phase 1: Metacognitive Analysis**: Explicitly analyze Where, How, Why, and I/O Contracts before writing code.
2. **Phase 2: Adversarial Simulation**: Dry-run edge cases, empty states, and concurrency vectors.
3. **Phase 3: Holistic Updates & Verification**: Make complete, single-pass edits validated by the Curator.

## 🔍 Kimi-Style Deep Research Protocol:
1. **Multi-Angle Decomposition**: Divide technical queries into 3-5 sub-queries (official docs, implementation repos, real-world benchmarks).
2. **Deep Source Inspection**: Fetch and parse full page content (
ead_url_content) and read raw GitHub source files.
3. **Multi-Hop Reflection**: Identify remaining ambiguities and trigger focused second-hop search passes.
4. **Structured Synthesis**: Output executive summary, architecture breakdown, trade-off matrix, verified code, and authoritative citations.
